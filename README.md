# Desafio Heroi – Classificador de Nível

Este repositório contém a solução do **Desafio Classificador de Nível de Herói**, realizado como parte do curso da plataforma DIO.

O objetivo do projeto é implementar uma lógica que classifica um personagem (herói) com base em atributos como nome, idade e tipo, e retorna uma descrição da ação de ataque de acordo com o tipo definido.

---

## 🚀 O que faz este projeto

Este programa em **Python**:

- Recebe dados de um herói (nome, idade e tipo);
- Classifica o herói de acordo com sua experiência e atributos;
- Retorna mensagens com estados/ataques diferentes conforme a regra definida;
- Demonstra conceitos de lógica de programação, orientação a objetos e manipulação de classes.

---

## 🧠 Conceitos aplicados

Este pequeno projeto foi desenvolvido para praticar:

- Estruturas de decisão e funções;
- Classes e objetos;
- Entrada e saída de dados no terminal;
- Boas práticas básicas de organização de código em Python.
